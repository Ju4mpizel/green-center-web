# Green Center Bolivia - Web Oficial

Sitio web oficial de Green Center Bolivia, importadora y comercializadora de vehículos eléctricos en Santa Cruz y Cochabamba. Desarrollado con Next.js 16 (App Router), Tailwind CSS y Framer Motion, optimizado para exportación estática en Cloudflare Pages.

## Requisitos

- Node.js >= 20 (Recomendado: Node 22)
- pnpm >= 9

## Comandos de desarrollo

```bash
# Instalar dependencias
pnpm install

# Iniciar servidor local
pnpm dev

# Validar reglas de código y linter
pnpm lint

# Compilar exportación estática para producción (genera carpeta /out)
pnpm build
```
